# Modèle Économique pour les Commerçants - Phase Pilote

Le modèle économique pour les commerçants partenaires de FOOD SIGNAL est conçu pour être attractif et incitatif pendant la phase pilote.

## Structure de Rémunération et de Coûts

1. **Commission sur les Ventes**
   FOOD SIGNAL prélève une commission sur chaque commande réalisée via la plateforme. Le taux de commission est réduit pendant la phase pilote pour encourager l'adoption.

2. **Pas de Frais d'Abonnement fixe**
   Les commerçants ne paient pas de frais fixes pour accéder à la plateforme ou pour lister leurs produits pendant la phase pilote.

3. **Visibilité Accrue**
   Les commerçants bénéficient d'une exposition directe aux demandes des clients locaux, générant du volume additionnel.

4. **Gestion Logistique**
   Les frais de livraison sont à la charge du client final, sauf accord spécifique. Les commerçants gèrent la préparation des commandes.
